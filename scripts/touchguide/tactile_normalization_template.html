触觉归一化：从力值到 DINO 输入

这个页面检查数值映射，不给样本标注任务成功／失败。增强触觉来自局部接触合成，并非物理仿真的真值。全量分布统计覆盖所有原始接触点；下面六组配对特意选取不同变化，不能当作总体比例。

1. 当前实际使用的规则

P = 0.5 + asinh(F / RMS) / (2 × asinh(32))
Z = (P − ImageNet mean) / ImageNet std

F 是每个接触点的力（N）。五指共用三个通道的固定 RMS；不按手指或样本重新缩放。零力映射为 0.5；±32×RMS 映射为 0 和 1。模型输入不截断，超过参考范围的值保留。

RMS 包括零力点。现用值来自旧干净训练集；表中另外两行只作尺度比较，均仅用训练集计算，本页不修改训练配置。

4. 怎样判断有没有问题

进一步查看：合力、接触位置与 DINO 特征的信息保留统计

先看接触变化是否仍能被映射区分，再检查极少数参考范围外值。高力区的差值会被 asinh 压缩，但在原始接触点上函数仍单调，没有把不同力值硬截成同一个值。接近零力时的变化保留得更明显。

数值检查通过不等于 DINO 能正确理解力图，也不等于打分器会利用触觉。下一层验证需要检查触觉特征变化、触觉消融和真实执行效果。
